# Steam File Transfer

같은 공유기에 연결된 Steam 기기끼리 **게임 폴더를 통째로 동기화**하는 도구입니다.
Windows PC, Steam Deck, Steam Machine, macOS에서 동작하며 어느 기기에서든 다른 기기로 보낼 수 있습니다.

```
[Windows PC]  ⇄  [Steam Deck]  ⇄  [Steam Machine]
   같은 공유기 아래에서 서로를 자동으로 찾고, 게임을 고르면 바뀐 파일만 넘어갑니다
```

홈페이지: <https://ddukbaek2.com/steam-file-transfer>

## 왜 만들었나

한글패치의 대부분은 Windows용 설치 프로그램으로 배포됩니다. SteamOS에서는 그 설치 파일을 실행할 수 없습니다. 그래서 스팀덱에 한글패치를 넣으려면 데스크톱 모드로 전환하고, 패치 파일을 따로 받아 두었다가, 게임 폴더를 찾아 들어가 손으로 덮어써야 했습니다. 게임마다, 패치가 갱신될 때마다 반복입니다. 설치형 패치는 그마저도 안 됩니다.

그런데 Proton 덕분에 **Steam 게임의 파일은 Windows와 SteamOS에서 동일**합니다. 실행 파일도 리소스도 같습니다. 그렇다면 패치 파일을 따로 관리할 필요가 없습니다. **이미 패치가 적용된 기기의 게임 폴더를 다른 기기로 통째로 덮어쓰면 됩니다.** Windows PC에서 설치형 패치를 평소처럼 적용한 뒤, 그 게임을 스팀덱으로 보내면 끝입니다.

이것이 이 프로젝트의 출발점입니다. 원리만 보면 FTP로 폴더를 복사하는 것과 다르지 않습니다. 다만 매번 IP를 찾고 SSH를 켜고 경로를 더듬는 일을 없애고, 바뀐 파일만 보내고, 무선이 끊겨도 게임 폴더가 망가지지 않게 만들었습니다.

## 어떻게 쓰나

설정 화면이 없습니다. 각 기기에 한 번 설치하면 그다음부터는 켜 두기만 하면 됩니다. 특히 SteamOS 쪽은 설치 뒤로 아무것도 만질 일이 없습니다.

앱을 켜면 화면이 셋으로 나뉩니다. 패널 사이 경계를 끌어 크기를 바꿀 수 있고, 더블클릭하면 원래대로 돌아옵니다.

**게임 목록**
이 기기의 Steam 라이브러리 전부를 훑어 게임을 아이콘, 이름, 설치 경로와 함께 보여 줍니다. 라이브러리 루트가 여러 개(내장 저장소, SD 카드, 다른 드라이브)여도 한 목록에 묶입니다. **폴더 열기** 아이콘은 탐색기에서 그 폴더를 엽니다. 전송은 여기서 하지 않습니다.

**기기 목록**
맨 위가 이 기기이고, 아래로 같은 내부망에서 이 앱이 켜진 기기가 자동으로 나타납니다. 다른 기기를 누르면 그 기기의 게임 목록으로 들어가고, 뒤로 가기로 돌아옵니다. 게임 항목에는 **보내기** 아이콘이 있습니다. 이 기기의 파일로 그 기기의 같은 게임을 덮어씁니다. 반대 방향으로 옮기고 싶으면 그 기기에서 이 기기를 골라 보내면 됩니다.

**전송 상태**
보내기는 큐에 쌓여 차례로 진행됩니다. 여러 게임을 연달아 눌러 두면 됩니다. 각 작업의 진행률, 현재 파일, 결과가 FTP 클라이언트처럼 표시되고, 이 기기로 들어오는 수신도 여기에 보입니다. 항목마다 **일시정지**, **재개**, **취소**, 끝난 뒤에는 **제거** 아이콘이 있습니다. 일시정지하면 파일 경계에서 멈추고 큐에 남으며, 그동안 다음 작업이 진행됩니다. 기록은 파일로 남아 앱을 다시 켜도 그대로이며, **완료된 항목 지우기** 아이콘을 누르면 비워집니다.

같은 게임을 다시 보내면 전송할 파일이 0개로 나옵니다. 파일마다 해시를 비교해 바뀐 것만 보내기 때문입니다.

## 안전하게 덮어쓰기 위한 장치

게임 폴더를 지우고 새로 쓰는 도구라 다음을 지킵니다.

- **임시 폴더에 전부 받은 뒤 한 번에 교체합니다.** 파일은 같은 볼륨의 임시 폴더로 먼저 들어가고, 전부 도착했을 때만 게임 폴더의 파일과 자리를 바꿉니다. 무선이 끊겨도 게임 폴더는 멀쩡하고, 다시 시도하면 이미 받은 파일은 건너뛰고 이어받습니다.
- **대소문자를 맞춥니다.** SteamOS는 `Data/Text.loc`과 `data/text.loc`을 다른 파일로 봅니다. 디스크에 있는 실제 철자를 찾아 그 파일을 덮어쓰므로 중복 파일이 생기지 않습니다.
- **위험한 쓰기를 거부합니다.** 같은 이름의 폴더를 파일로 덮어쓰려 하거나, 게임 폴더 밖을 가리키는 심볼릭 링크에 쓰려 하면 받기 전에 거부합니다.
- **끝나면 전체 파일을 검사합니다.** 모든 파일이 원본과 같은지 확인해 알려 줍니다. 게임이 실행 중이라 잠긴 파일이 있으면 여기서 드러납니다.

되돌리기 기능은 따로 없습니다. 원본으로 돌아가려면 Steam의 **게임 파일 무결성 확인**을 쓰면 됩니다.

## 설치

### Steam Deck / Steam Machine

Decky Loader와 같은 방식입니다. 데스크톱 모드에서 한 번만 하면 됩니다.

1. [릴리스 페이지](https://github.com/ddukbaek2/steam-file-transfer/releases/latest)에서 `steam-file-transfer-installer.desktop`을 내려받습니다.
2. 내려받은 파일을 더블클릭합니다. "실행할까요?"라고 물으면 실행을 고릅니다.
3. 터미널 창이 열리고 설치가 진행됩니다. 끝나면 기기 이름과 IP가 표시됩니다.

백그라운드 서비스로 등록되어 게임 모드에서도, 재부팅 후에도 계속 대기합니다. 홈 디렉터리에만 설치하므로 SteamOS 시스템 업데이트에도 살아남습니다. 새 버전이 나오면 같은 파일을 다시 더블클릭하면 됩니다.

```bash
systemctl --user status steam-file-transfer     # 상태 확인
journalctl --user -u steam-file-transfer -f     # 로그 보기
bash ~/.local/share/steam-file-transfer/resources/steamdeck/uninstall.sh   # 제거
```

직접 설치하려면 릴리스에서 tar.gz를 받아 풀고 `bash resources/steamdeck/install.sh`를 실행합니다.

### Windows

설치 파일을 실행합니다. 방화벽 규칙이 자동으로 등록되어 허용 팝업이 뜨지 않습니다. 사설망에만 열리고 공용 와이파이에서는 노출되지 않습니다. 무설치 실행 파일도 있습니다.

### macOS

`.dmg`를 열어 응용 프로그램으로 끌어다 놓습니다. 서명이 없어서 첫 실행은 우클릭 후 열기로 해야 합니다.

### 백그라운드 서비스와 창

이 앱은 백그라운드 서비스와 화면이 분리되어 있습니다. 창을 닫아도 서비스는 트레이에 남아 계속 받습니다. 다시 실행하면 새 창이 열립니다. Windows와 macOS에서는 로그인할 때 자동으로 백그라운드 시작됩니다. 완전히 끝내려면 트레이 아이콘의 **종료**를 누릅니다.

## 안 될 때

**기기가 안 보입니다**
두 기기가 같은 공유기에 붙어 있는지 확인합니다. 게스트 와이파이나 2.4GHz와 5GHz가 분리된 망에서는 서로 보이지 않습니다. 공유기의 "AP 격리"를 끄면 해결되는 경우가 많습니다. Windows에서 네트워크가 공용으로 잡혀 있으면 사설망으로 바꿉니다.

**게임 목록이 비어 있습니다**
Steam이 비표준 위치에 있거나 Flatpak, Snap으로 설치된 경우입니다. 환경 변수 `SFT_STEAM_ROOT`에 Steam 루트 경로를 넣고 앱을 다시 시작하면 그 위치를 읽습니다. 목록에는 Steam 클라이언트가 설치된 것으로 아는 게임만 나옵니다. 지운 게임의 폴더가 남아 있어도 보이지 않습니다.

**보냈는데 게임이 그대로입니다**
전송 상태의 검증 결과에 "다름"이 있으면 게임이 실행 중이라 파일이 잠겨 있었을 가능성이 큽니다. 게임을 끄고 다시 보내세요. 이어받기라 금방 끝납니다.

**전송 상태에 "수신 포트를 다른 프로그램이 쓰고 있다"고 나옵니다**
다른 프로그램이 37021 포트를 잡고 있습니다. 그 프로그램을 끄고 앱을 다시 시작합니다. 보내기는 이 상태에서도 됩니다.

## 보안

내부망 전용 도구입니다. 인터넷에 노출하지 마세요.

인증이 없습니다. 같은 공유기 아래면 바로 주고받습니다. 대신 쓸 수 있는 곳은 Steam 게임 폴더 안으로만 제한되어 있어서, 경로 탈출과 게임 폴더 밖으로 나가는 심볼릭 링크 쓰기는 항상 차단합니다. Windows 방화벽 규칙도 사설망 프로필에만 열립니다.

## 개발

Node 22 이상이 필요합니다. 런타임 의존성은 없습니다. HTTP 서버와 클라이언트, UDP 탐색, Steam 설정 파일 파서를 전부 Node 내장 모듈로 만들었습니다.

```bash
npm install
npm start              # 개발 실행
npm test               # 단위 + 네트워크 + 안전장치 테스트
npm run e2e            # 데몬 두 개를 별도 프로세스로 띄워 실제 전송까지
npm run smoke          # GUI 를 띄워 렌더링 확인 (스크린샷 저장)
npm run typecheck

npm run dist:win       # Windows 설치판 + 무설치판
npm run dist:linux     # Linux tar.gz (SteamOS)
npm run dist:mac       # macOS dmg
```

`v*` 태그를 밀면 GitHub Actions가 세 OS용 빌드를 만들어 릴리스에 올립니다. 설계 배경과 구현 세부는 [DESIGN.md](DESIGN.md)에 있습니다.
